# カジュアル対戦カードゲーム開発案

## プレイ人数
- 1対1

## 対戦形式
- ターン制、妨害割り込みあり ←同時行動制？

## 1試合の長さとゲーム展開
- 3分or5分
- あくまでカジュアルゲームの予定なので長すぎないように
- 逆転要素もあると良い
- （例）10ターン経過するとミッション達成に必要な条件が緩和される
- （例）ターン経過に応じて強力なカードが使えるようになる
- （例）山札が一定枚数以下になるとゲーム終了が近づく
- （例）一定ターンごとに全プレイヤーにイベントが発生する

## 勝利条件
- ライフポイント制にはしたくない
- ハースストーンのクエストのランダム版みたいなものをベースに考えている
- 対戦開始時にランダムな選択肢が3つ表示され、1つ選んでその条件を先に達成した方が勝利
- 自分と相手の選択肢は被ることもあるし全部違う場合もある（異なる条件達成をお互いに目指す）

## 敗北条件
- 先にミッションを達成されたら負け
- 山札切れは負け扱いにしない
- 何か特別な状況になった場合…要検討

## 引き分け
- 基本的にはなしの方向
- どちらも条件達成できなかった場合は条件により近い方
- それも同じ場合はどうするか？

## ゲーム終了条件
- どちらかの勝利
- 規定ターン数の経過

## 先攻・後攻
- 対戦開始時にランダム決定

## 先攻有利への対策
- 初期手札の差、先攻1ターン目の制限など

## 手札枚数・デッキ枚数
- 初期手札は他のDCGを参考に5枚前後？
- 手札上限は設けない
- デッキ枚数は20～30枚くらいにとどめたい
- 同名カードは2～4枚くらい？無制限だと多分面白くなくなる
- カードの引き方にも手を加える？例えば毎ターンデッキから1枚探索して手札に加えるなど

## デッキ構築するか
- ここはカードゲームの楽しみの一つなのでできるだけ入れたい
- 特定カードは固定にして残りを可変にするというパターンも？
- テストプレイ時は固定式をランダムに配るのもあり
- ミッションに応じて自動調整 → ある意味理想だがかなり難しそう

## いわゆる場を設けるか
- モンスターなどを戦わせるゲームでは場にモンスターカードを出すが、トランプのババ抜きなどのように手札で完結するものもある
- ミッションの進行状態がわかるのも駆け引きの一つなので、何かでわかるようにしたい
- カードの破壊/再利用を想定するか → いわゆる墓地や使用不可領域のようなものが必要になる

## カードの種類
- 勝利条件に関連する
- ダメージを与えて戦うゲームにはしない方針なので、モンスターとか武器のようなカードは登場させない
- 純粋にミッション達成に関わるカードと他に相手を妨害するカード（何かを打ち消す、相手のリソースを奪うなど）も一定枚数以下まで採用可能にしたい（参考：マジック・ザ・ギャザリングの青系統の呪文）
- 妨害の種類：破壊、奪取、強制交換、処理打ち消し、行動制限、ミッション進行度妨害など
- ドロー、手札交換、デッキ内探索

## ゲームのシナリオ・ストーリー性
- ゲーム性やカードの種類とも絡むが、そのカードが存在する理由や結びつきがないと弱い
- デッキを遺跡か何かに見立てて、そこからロボットor乗り物のパーツを探し出して先に完成させた方が勝ち（頭脳、骨格、腕、脚など4～5くらいのパーツにする）？？？
- 上記に組み合わせて、例えば赤のカードを3枚集めてロボットを赤色にする/赤のエネルギーを与える、みたいにする？

## ミッションの種類
ChatGPTの例から引用
>A. カード収集型
>指定されたカードや属性を集める。
>- 火属性カードを3枚集める
>- 同じ数字のカードを4枚集める
>- モンスターカードを5枚場に出す
>
>B. 組み合わせ完成型
>特定のカードの組み合わせを作る。
>- 赤・青・緑のカードを揃える
>- 連番3枚を揃える
>- 特定のカードと特定のアイテムを組み合わせる
>
>C. 場の状態達成型
>自分の場を指定された状態にする。
>- 場にカードを4枚並べる
>- 同じ属性のカードを3枚配置する
>- 場のカードの合計値を15にする
>
>D. イベント達成型
>ゲーム中に特定の出来事を発生させる。
>- 相手のカードを3枚破壊する
>- カード交換を2回行う
>- 特定のイベントカードを引く
>
>E. リスク挑戦型
>運試しや危険な行動を成功させる。
>- 連続でカードを3枚引く
>- 特定の確率判定に成功する
>- 失敗すると進捗がリセットされる挑戦を成功させる
