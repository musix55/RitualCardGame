# プロトタイプ v0.1
## 仮ルール・要テスト
ロボットのパーツを集め、相手より先に完成させる1対1対戦。

ゲーム開始
- 各プレイヤーにランダムなミッション候補を3つ提示
- 1つ選択し、相手には非公開
- 初期手札5枚
- 先攻・後攻はランダム
  
  自分のターン
1. 山札から1枚ドロー
2. 2アクションを実行
3. ターン終了時に勝利判定
   
   カードの種類
- パーツカード：場に配置してミッションを進める
- サポートカード：ドロー、交換、探索
- 妨害カード：相手のパーツを一時的に無効化、奪取、破壊
  
  場のルール
- 各プレイヤーに4つのパーツスロット
- 場のカードは基本的に公開
- 妨害によってカードが場から離れることがある
  
  勝利条件
- ミッションを達成したプレイヤーが勝利
- 同時達成時は先攻・後攻に関係なく引き分けとし、追加判定へ
- 最大10ターンで終了し、進捗ポイントで勝敗判定
  
  デッキ
- 30枚
- 固定デッキを使用
- 同名カード上限3枚
- 手札上限なし

これは完成版の仕様ではなく、実際に遊んで問題点を洗い出すための土台です。

## 具体化案
### ゲームのテーマとカードの役割
あなたはとある遺跡からロボットの素体となる骨格と壊れたパーツ一式を発掘しました。
デッキを掘り進めてロボットを完成させるのがゲームの目的です。
4つのパーツスロットは頭脳、胴体、両腕、両脚とします。
集めるのは修理や強化に必要となる素材です。

### ミッションを10種類ほど作る
収集型、組み合わせ型、場の状態型などを混ぜ、達成条件の幅を確認します。
1. 同じ色で4パーツを統一する
2. 4パーツとも違う色にする
3. 一定ターン以内にロボットを完成させる
4. 手札が一定枚数以上の状態でロボットを完成させる
5. 相手の素材を1つ以上奪ってロボットを完成させる
6. 対戦中にカードをN枚以上手札に加える
7.

### 必要なカードを定義する
- 4色の素材カード（赤・青・緑・黄色）
- ドローカード
- 手札入れ替え
- 探索（デッキ内のカードからランダムな3択を表示して1枚選ぶ？）

### 妨害カードを5種類ほど作る
   破壊、交換、無効化、ドロー妨害などを試し、妨害が強すぎないか確認します。

### 紙上で数試合プレイする
   デッキ30枚、初期手札5枚、2アクション制などの仮ルールで、勝敗が決まるまでの流れを確認します。
### 問題点をもとにルールを修正する
   試合が長い、ミッションの難易度に差がある、妨害が強すぎる、といった点を調整します。
